# Política de Privacidade — Puzzle Fables

Esta página existe por uma exigência da Google Play: a ficha do aplicativo
precisa apontar para uma política de privacidade em URL pública e estável.

Publicada em <https://rafaelrubio21.github.io/puzzle-fables-privacidade/>.

Repositório separado de propósito — o código do jogo é privado, e só esta
página precisa ser pública.

**Se o conteúdo do aplicativo mudar** (novo SDK, nova coleta de dados), atualize
esta página *antes* de publicar a versão, e altere a data no topo do arquivo.
Declaração de privacidade que não bate com o comportamento real do app é
violação de política.
